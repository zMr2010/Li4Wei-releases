# 理四维 Li4Wei

在三维切片里探索四维世界。戴上头显，转动切片寻找出口，观察四维物体经过时留下的形状。

[下载 v0.1.1 APK](../../releases/download/v0.1.1/Li4Wei-v0.1.1.apk)

[下载上一版 v0.1.0 APK](../../releases/download/v0.1.0/Li4Wei-v0.1.0.apk)

安装包适用于支持 OpenXR 的 PICO 和 Meta Quest ARM64 头显。开启开发者模式与 USB 调试后，可在电脑上安装。

```sh
adb install -r Li4Wei-v0.1.1.apk
```
